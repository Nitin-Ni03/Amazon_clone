# Amazon Clone

A responsive Amazon homepage clone built with HTML and CSS to replicate real-world e-commerce design principles.

## Overview

This project demonstrates the implementation of a modern e-commerce website interface using semantic HTML and advanced CSS techniques. It includes a fully functional login page and a homepage with product showcases.

## Features

- **Responsive Design**: Adaptive layout using CSS Flexbox and Grid for all screen sizes
- **Semantic HTML**: Well-structured markup for improved accessibility and SEO
- **Login Page**: A dedicated authentication interface with styled form elements
- **Product Showcase**: Grid-based product display with product images
- **Navigation Bar**: Header with logo and navigation elements
- **Professional Styling**: Modern CSS with attention to visual hierarchy and user experience

## Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with Flexbox and Grid layouts
- **Responsive Design** - Mobile-first approach with media queries

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser to view the homepage
3. Click on login elements to navigate to `login.html`
4. Explore the responsive design by resizing your browser window

## Files Description

- **index.html** - Main homepage featuring product grid and navigation
- **login.html** - User authentication page with login form
- **style.css** - Styling for the homepage including layout, colors, and animations
- **login.css** - Styling specific to the login page
- **asset/** - Directory containing all images (logos, product images, hero image)
